# EE-501 Artificial Intelligence

Welcome to the EE-501 Artificial Intelligence repository. This repository serves as a resource for students and enthusiasts to explore and understand fundamental AI concepts through interactive tools and practical applications.

## 📁 Repository Structure

The repository is organized into multiple branches, each focusing on different aspects of Artificial Intelligence:

### 1. `main` (default branch)

* **Purpose:** Contains foundational resources and introductory materials for the course.
* **Contents:**

  * Lecture slides and notes
  * Basic AI concepts and algorithms

### 2. `custom-dataset-support`

* **Purpose:** Provides tools for working with custom datasets in AI projects.
* **Features:**

  * Instructions for uploading and processing custom datasets
  * Scripts for data preprocessing and augmentation
  * Example projects demonstrating dataset integration

### 3. `single-perceptron`

* **Purpose:** Offers an interactive visualization of a single-layer perceptron.
* **Features:**

  * Real-time input-output mapping
  * Adjustable weights and bias
  * Visualization of decision boundaries
  * Excel-based implementation for designing and simulating logic gates (AND, OR, etc.) using a single perceptron

### 4. `MLP-Visualizer`

* **Purpose:** Provides tools for visualizing Multi-Layer Perceptrons (MLPs).
* **Features:**

  * Interactive MLP architecture builder
  * Visualization of training processes
  * Performance metrics and evaluation tools
  * Deployed on Hugging Face for easy access: [MLP Visualizer on Hugging Face](https://huggingface.co/spaces/Umar1623/MLP-visualizer)

## 🚀 Getting Started

To get started with the repository:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/umar-1623/EE-501-AI.git
   cd EE-501-AI
   ```

2. **Install Dependencies:**

   Ensure you have Python 3.8+ installed. Then, install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. **Select a Branch:**

   Checkout the branch relevant to your interest:

   ```bash
   git checkout [branch-name]
   ```

4. **Run the Application:**

   For interactive applications (e.g., Streamlit or Flask apps), run the respective scripts:

   * For Streamlit apps:

     ```bash
     streamlit run app.py
     ```

   * For Flask apps:

     ```bash
     python backend/app.py
     ```
